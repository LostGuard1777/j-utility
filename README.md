# j-utility
A Java utility library.

![Version: 1.1](https://img.shields.io/badge/Version-1.0-blue.svg)

## Contents
- `Util` class for general utility functions
- `RiemannSum` functional interface for calculating indefinite integrals

> To read documentation, check the `Docs` Folder in the root level or `Geo.Docs` for documentation of geometry.

## To use
Add this line to your Java file:
`import utility.*;`
> **NOTE:** To just import utility functions, use
> `import utility.Util;`
